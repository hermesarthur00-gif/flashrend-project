# StatusBadge

Statut normalisé d'une opération (dépôt, retrait, investissement), icône et libellé inclus.

**Props** : `status` (`completed`, `pending`, `processing`, `failed`), `children` pour remplacer le libellé.

- Libellés par défaut : Effectué, En attente, En cours, Échoué.
- Dans une liste, n'affichez pas `completed` : l'absence de badge veut dire « effectué ».
