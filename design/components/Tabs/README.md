# Tabs

Onglets segmentés ou soulignés.

**Props** : `items` (chaînes ou `{ value, label }`), `value` / `defaultValue`, `onChange`, `variant` (`segmented` par défaut, `underline`), `block`, `label`.

- `segmented` : 2 à 5 choix courts qui changent une vue (Investir / Retirer, périodes de graphique).
- `underline` : sections d'un écran de détail (Actifs, Activité, Infos).
