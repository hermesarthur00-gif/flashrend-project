# Modal

Feuille qui monte du bas sur mobile, boîte de dialogue centrée à partir de 640px.

**Props** : `open`, `onClose`, `title`, `children`, `footer` (boutons).

- Échap et un clic sur le voile ferment ; le focus va dans la feuille à l'ouverture.
- Pied : action principale à droite sur desktop, en haut de la pile sur mobile.
- Réservée aux confirmations (retrait, vente) et aux choix courts.
