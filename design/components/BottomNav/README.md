# BottomNav

Navigation principale mobile en 5 entrées, l'action Investir au centre en jaune.

**Props** : `items` (`[{ value, label, icon, primary? }]`), `value` / `defaultValue`, `onChange`.

- Fixée en bas de l'écran sur mobile ; au-delà de 1024px, remplacez-la par une barre latérale avec les mêmes entrées.
