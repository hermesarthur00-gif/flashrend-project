# Icon

Icônes Tabler en contour (MIT), épaisseur 1,75 par défaut, couleur héritée de `color`.

**Props** : `name` (nom Tabler), `size` (20 par défaut), `stroke`, `label` (rend l'icône lisible par les lecteurs d'écran ; sinon elle est décorative).

- Tailles : 16 dans les badges et petits boutons, 20 dans les boutons et champs, 22 à 24 en navigation.
- Le bundle embarque un jeu restreint : home, chart-line, wallet, arrows-exchange, building-bank, arrow-up-right, arrow-down-left, arrow-up, arrow-down, arrow-right, chevron-*, x, check, plus, minus, search, eye, eye-off, bell, user, settings, logout, clock, copy, info-circle, alert-triangle, alert-circle, circle-check, shield-check, id, file-upload, camera, refresh. En production, importez `@tabler/icons-react`.
- Pas d'emoji à la place d'une icône, pas d'icône « étincelles ».
