# CryptoIcon

Pastille d'actif dans la couleur de marque de la crypto, avec son symbole monétaire.

**Props** : `symbol` (`BTC`, `ETH`, `BNB`, `DOGE`, `USDT`, `SOL`), `size` (36 par défaut), `src` (URL d'un logo officiel pour remplacer la pastille).

- Les couleurs viennent des tokens `crypto-*`. Elles ne servent qu'ici et dans `AllocationDonut`.
- En production, passez les logos officiels via `src` (paquet `cryptocurrency-icons`) ; la pastille reste le repli.
