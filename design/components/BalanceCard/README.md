# BalanceCard

Carte noire (`band`) du solde total, en tête de l'accueil. Le montant peut être masqué.

**Props** : `amount`, `gain` (gain ou perte en $ depuis le début), `gainLabel`, `label`, `children` (deux boutons d'action).

- Une seule par écran, en haut de l'accueil.
- Actions : `Button variant="primary"` (Déposer) puis `variant="secondary"` (Retirer).
