# IconButton

Bouton carré ne contenant qu'une icône. `label` est obligatoire (aria-label et infobulle).

**Props** : `icon`, `label`, `variant` (`ghost` par défaut, `secondary`, `primary`), `size` (`sm`), `badge` (pastille de notification).

- 44px de côté par défaut pour rester touchable au doigt.
- `primary` seulement pour l'action « Investir » flottante ou dans la barre basse.
