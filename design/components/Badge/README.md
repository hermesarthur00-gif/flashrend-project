# Badge

Étiquette d'un ou deux mots. Le ton porte un sens, jamais décoratif.

**Props** : `tone` (`neutral`, `flash`, `up`, `down`, `warning`, `info`, `dark`), `icon` (optionnel), `children`.

- `flash` : nouveauté, mise en avant marketing.
- `up` / `down` / `warning` / `info` : états. Ajoutez une icône quand le badge est seul pour porter le sens sans la couleur.
- Pour un statut d'opération, utilisez `StatusBadge`.
