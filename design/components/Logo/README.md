# Logo

Le logo FlashInv en SVG inline : symbole seul ou version horizontale avec le logotype.

**Props** : `variant` (`horizontal` par défaut, `symbol`), `size` (hauteur en px, 32 par défaut), `tone` (`auto` suit le thème ; `light` pour un fond clair ; `dark` pour un fond sombre ou `band`).

- Utilisez `variant="symbol"` sous 120px de large disponible (header mobile, favicon, avatar d'app).
- Sur un bloc `flash`, gardez `tone="light"` : carré noir, éclair jaune.
- Ne recolorez jamais l'éclair, ne l'étirez pas, n'ajoutez pas d'ombre.
- Zone de protection : la moitié de la hauteur du symbole tout autour.
