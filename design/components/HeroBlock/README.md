# HeroBlock

Hero du site public : bloc `flash` avec chapeau, appels à l'action et visuel, puis bande `band` avec le grand titre en Batica.

**Props** : `eyebrow`, `lead`, `cta`, `secondary`, `title`, `media` (nœud React : cartes de cours flottantes, rendu 3D).

- Le titre vit dans la bande noire, en `display-xl` desktop et `display-lg` mobile.
- Le visuel : cartes de cours avec `shadow-float`, pièces 3D noires et jaunes. Animations d'entrée orchestrées au scroll avec GSAP (voir le README).
